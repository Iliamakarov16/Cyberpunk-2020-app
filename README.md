# Night City Crew 0.17.7-mobile.1

Игровая сборка с обновлённой 2D-картой Atlas, существующим общим боем и русской памяткой подключения/сохранения. Установочный APK поставляется отдельно. Начни со [START_HERE.md](START_HERE.md).

Package `app.nightcity.crew.mobile`, versionCode170601 и прежний сертификат сохранены. Перед обновлением сохрани полную копию сервера; устанавливай поверх совместимой предыдущей версии, без удаления приложения.

Источник этого архива — сохранённая боевая основа0.17.5 с укрытиями и подтверждённая интеграция Atlas0.17.6. Незавершённый перевод, Aim и отдельный3D-прототип не включены. Приватные ключи, пароли, пользовательские базы и рабочие зависимости не включены.

- Проверить исходники: `python3 assemble_source.py`
- Восстановить сгенерированные файлы после установки зависимостей: `python3 assemble_source.py --build`
- Полные шаги: [README_REBUILD_0.17.6.md](README_REBUILD_0.17.6.md)
- Проверки и пределы: [QA_STATUS.md](QA_STATUS.md), [RELEASE_INFO.json](RELEASE_INFO.json)
- Возможности/ограничения правил: [COMBAT_RULES_SCOPE.md](COMBAT_RULES_SCOPE.md)

iPhone подключается в Safari к работающему Android-серверу в той же доступной сети. Отдельный приватный веб-стенд не хранит ваши реальные кампании. Автоматический подбор чужих предметов на поле ещё не реализован.
