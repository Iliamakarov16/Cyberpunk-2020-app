# Night City · Поле боя

Рабочий самостоятельный прототип тактического боя для кампании Cyberpunk 2020. Интерфейс рассчитан на горизонтальный телефон и работает на компьютере. Карта и оригинальные пиксельные изображения вдохновлены удобством пошаговых RPG; правила относятся к Cyberpunk 2020.

## Как попробовать

1. Открой сцену «Последняя остановка». По умолчанию выбран режим ГМа.
2. «Расставить» → выбери участника → клетку → подтверди размещение. Через «Карта» можно поставить стены, двери и ящики.
3. «Начать бой» бросает инициативу. Ведущий вручную управляет НПС.
4. Выбери «Идти» или «Огонь», коснись клетки/цели и подтверди действие в появившейся панели. Касание само по себе ничего не расходует.
5. «Завершить ход» передаёт очередь. У пистолета ROF 1: после выстрела можно перезарядиться или двигаться, но второй выстрел в этом раунде недоступен.
6. В ход Миры: «Сеть» → подключить деку к соседнему порту → «Найти устройства» → выбрать дверь, камеру или громкую связь → подтвердить команду.
7. Переключатель «ГМ / Игрок» показывает локальную демонстрацию двух интерфейсов. В режиме игрока можно выбрать Рэя или Миру.

**После обновления старый бой остаётся на месте.** Чтобы попробовать новое снаряжение и деку Миры, выбери «Сцена → Сбросить демонстрацию» либо «Новая сцена» в баннере ГМа. Сброс требует подтверждения; перед ним можно скачать прежний JSON.

Перед выстрелом показаны шанс и формула попадания, после — бросок, урон и результат. «Оглушён» означает живого персонажа: восстановление проверяется в начале его хода. Вспышка, трассер, отдача, гильза и разные эффекты попадания/промаха помогают читать событие. «Сцена → Звук выстрелов» включает короткий звук; по умолчанию он выключен. При reduced motion анимация заменяется статическим результатом.

Перетаскивание перемещает карту, щипок/колесо меняет масштаб, процент масштаба показывает всю карту. Сцена сохраняется в этом браузере. ГМ может скачать/загрузить JSON, приостановить бой и отменить последние 20 действий. Завершение боя сохраняет патроны, броню и ранения; сброс демонстрации — отдельное действие с подтверждением.

## Что реализовано

- Подготовка, расстановка, начало, пауза и завершение боя.
- Инициатива каждый раунд, очередность и проверки владения персонажем.
- Поиск маршрута с препятствиями, диагонали без срезания углов.
- Одиночный выстрел: дальность, WA, навык, REF, штраф последующих действий, критические броски и прицельные попадания.
- Броня по частям тела, BTM, ранения, оглушение, смертельный шок и дополнительное правило Staged Penetration.
- Двери и направление низкого укрытия; ровные столы и двери по осям клеток.
- Locate Remote и Control Remote: Genie, Crystal Ball и Soundmachine; дверь, камера и громкая связь.
- Шанс попадания, открытый бросок, различение брони, ранения, оглушения и гибели; визуальные и необязательные звуковые эффекты.
- Скрытые НПС: убраны из карты, имён, подробностей, журнала и будущей очереди игрока.
- Журнал, локальное сохранение, импорт с валидацией, защита от повторного применения одной команды.
- Компонент с параметрами для встраивания, чистый движок без React, экспорт исходников модуля.

## Границы версии

Это **локальная сцена**, а переключатель ролей — средство демонстрации, не авторизация. Другие телефоны не подключаются, приглашения и общий сервер ещё не реализованы. Ведущий управляет НПС вручную. Очереди, автоматический огонь, рукопашный бой, гранаты, прицеливание в течение нескольких раундов, кибернетические бонусы, прострел укрытий, полное погружение в Net/ICE и MicroNET не рассчитываются. Контроль локальных устройств реализован отдельным ограниченным набором. Последствия критического промаха и ограничения после уничтожения конечности остаются решением ГМа.

## Разработка

Проект использует React 19, Vinext/Vite, Canvas 2D, lucide-react и установленные компоненты Shadcn на Radix UI. Node.js ≥22.13, pnpm 11.25. Сохранены стандартные средства установки, сборки и размещения Sites.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm test
pnpm check
pnpm build
```

`lib/battle/engine.mjs` — правила и команды, `scene.mjs` — сцена и оружие, `net.mjs` — Controller-программы, `renderer.mjs` — карта/камера/эффекты, `audio.mjs` — звук. Компоненты в `components/battle/` отвечают за интерфейс, `app/globals.css` — за оформление. `python scripts/export_battle_module.py` обновляет архив для переноса и публикуемую инструкцию. В managed preview запуском управляет Sites.

38 автоматических проверок покрывают правила, повторные команды, версии, приватность обзора, валидацию импорта, контроль устройств, восстановление бюджета Net по раундам и жесты камеры. Сборка и проверка кода проходят. Карта визуально проверена через тот же Canvas-рендерер. Полная проверка в браузере на физическом телефоне остаётся отдельным шагом: браузерный предпросмотр был недоступен в среде сборки.
