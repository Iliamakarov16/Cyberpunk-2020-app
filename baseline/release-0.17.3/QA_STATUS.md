# Проверка 0.17.3-mobile.1

- Python: 155 тестов прошли, включая настоящий HTTP, транзакции, повторные запросы, конфликты, восстановление копий и перенос кампании.
- Frontend: все 52 скрипта `web-source/scripts/test-*.mjs` прошли на итоговом коде; TypeScript прошёл.
- Исходный модуль боёвки: 38 тестов прошли. Python-адаптер дополнительно сверяется с сохранёнными исходными JS-правилами.
- Java: 6 групп проверок, в том числе 668 проверок извлечения ресурсов и сохранности данных. Это запуск Java-кода, не эмуляция Android Activity.
- Реальный подписанный APK: проверены подпись v2/v3, неизменная подпись ветки 0.17, package/version/minSdk/targetSdk, DEX, ZIP, выравнивание и точные байты четырёх Python-модулей и веб-ресурсов. Временный сервер запущен из содержимого APK; HTTP-проверка получила все 193 ресурса, включая 50 зависимостей входных страниц.
- Atlas: отдельный полный набор DOM/данных/NCART и настоящий JS-редактор против HTTP-сервера Crew. Проверены роли, CSRF, закрытые заметки, конфликты, повтор, смена аккаунта, Back, восстановление размеров и ошибки локального хранения. Все 105 файлов установленного клиента сверены по хэшам с проверенной версией.
- Независимый просмотр исходников нашёл и помог закрыть потери настроек износа, состояния персонажей и локальных заметок; оставшихся найденных блокеров в проверенной области нет.

## Что не выдаётся за проверенное

Реального Android/iPhone нет. Интерактивный браузерный рендер изменённой сборки заблокирован инфраструктурой. Ориентация Activity, экранная клавиатура, системный выбор файлов и посадка вёрстки на телефоне требуют проверки на устройстве. Отдельные изображения картографии были сгенерированы и просмотрены; это не скриншоты мобильного приложения.

Точечный ESLint новых Atlas/боевых/навигационных компонентов: 0 ошибок, 5 предупреждений зависимостей hooks в shared-battle. Более широкая проверка Tracker, CampaignHub и TransferPanel по-прежнему содержит 54 ошибки и 24 предупреждения существующего линтера. Их количества и наборы правил совпадают с 0.17.2; общая чистота ESLint не заявляется. Android lintVitalRelease прошёл.

## Повторение проверок

Из корня: `python3 assemble_source.py`, затем `python3 -m unittest discover -s tests -p 'test_*.py'`.

В `web-source/` после установки зависимостей из lockfile: `npx tsc --noEmit`; запустить каждый `scripts/test-*.mjs` через Node. Для веб-сборки: `node scripts/build-selfhost.mjs ABSOLUTE_OUTPUT_DIRECTORY`.

В `atlas-source/`: `npm ci`, затем `CREW_ATLAS_SOURCE=.. npm run check`. Его отдельный исторический backend не нужно подключать к SQLite Crew. Рабочий сервер меток Crew находится в `android/app/src/main/python/crew_atlas.py`.

Полная резервная копия сервера и перенос кампании имеют разный состав. Текущее состояние совместного боя сохраняет именно полная копия сервера; экспорт сцены сохраняет только безопасный шаблон подготовки. Подробности в START_HERE.md.
