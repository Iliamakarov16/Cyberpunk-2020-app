# Проверка 0.17.4-mobile.1

## Основание изменения интерфейса

Просмотрены два настоящих снимка телефона с 0.17.3: переполненная подготовка и форма, перекрытая клавиатурой. В текущем кандидате поле освобождено от постоянной пустой карточки; действия открываются у выбранного героя, меню и камера не перекрывают друг друга. Подготовка и инструменты сцены используют всю видимую область и отдельную прокрутку.

## Проверки

- Python: 170 тестов прошли. Включают настоящий HTTP, совместные действия и сохранение, права/приватность, повторы, конфликты, восстановление копий, перенос кампаний, броню, NET, автомобили и все сочетания 12 внешностей с тремя исходными шаблонами NPC. Правила сравниваются с сохранённым исходным JS-модулем.
- Проверен настоящий файл гаража: GM импортирует пустую сцену, player не может, повтор не дублирует, 26 клеток машин и остальные данные сохраняются при экспорте, реальные листы не меняются.
- TypeScript selfhost прошёл. Точечный ESLint изменённых игровых компонентов: 0 ошибок, 5 существующих предупреждений зависимостей hooks в shared-battle. Общая чистота линтера проекта не заявляется.
- Все 57 frontend-скриптов прошли на итоговом коде. Сборка release и Android lintVitalRelease прошли. DEX, binary manifest, ZIP и выравнивание проверены. Из самого итогового APK запущен временный сервер: 58 зависимостей страниц и все 201 публичный ресурс получены по HTTP с точным совпадением байтов; четыре Python-модуля совпадают с исходниками. Шесть групп Java-проверок прошли, включая 684 проверки извлечения и сохранности данных. SDK и независимая проверка подтверждают подпись v2/v3, постоянный package и сертификат. Добавлен тест соответствия нативной метки извлечения ресурсов версии APK.
- Настоящий React/Radix Dialog смонтирован в JSDOM: открытие не фокусирует поле ввода само, visualViewport меняет размеры/смещение, активный ввод остаётся выбранным и прокручивается в видимую область, обработчики удаляются при закрытии. Это не эмуляция экранной клавиатуры и не измерение пикселей.
- Настоящий BattleRenderer отрисован через canvas: четыре прежних и восемь новых персонажей, ортогональная мебель, машина и фургон. Просмотрены полученные пиксели. PNG новых внешностей совпадают с исходными хэшами и заданными crop; внешность не даёт оружия, брони, щита или особых действий.
- Независимая проверка управления и внешностей закрыла найденные проблемы: Space на кнопке больше не завершает ход, доступны оба собственных героя, Escape закрывает панель из фокуса кнопки, широкий спрайт выбирается по видимому краю, отложенная загрузка изображения после выхода не перерисовывает уничтоженный экран.
- 365 записанных хэшей исходников и ресурсов Atlas совпадают с принятой 0.17.3. Полный отдельный набор Atlas заново не запускался; актуальные интеграционные HTTP/навигационные проверки входят в общие наборы.

## Ограничения

APK подписан новым постоянным ключом для app.nightcity.crew.mobile. Он устанавливается отдельно от прежней ветки .next. Владелец лично сохранил приватный комплект в Drive; скачанная оттуда копия восстановлена в отдельной закрытой папке и создала побайтово тот же подписанный APK. Приватный комплект отсутствует в исходниках и Library. Реальная установка телефона не проверялась.

Chromium не удалось запустить из-за ограничений socket/ptrace среды. Другой обход этих ограничений не применялся. Реального Android/iPhone нет: новая посадка HUD, системная клавиатура, поворот Activity и системный выбор файлов требуют проверки на устройстве после появления подписанной сборки. Canvas-рендер и DOM-тесты не заменяют её.

Машины являются статическими препятствиями/укрытиями, без новых правил автомобильного боя. Внешности косметические. Исходные незавершённые механики очередей, гранат, рукопашной и полного Net/MicroNET не объявляются готовыми. Экспорт кампании, шаблон сцены и полная резервная копия сервера сохраняют разный состав данных; подробности в START_HERE.md.

## Повторение

Из корня: `python3 assemble_source.py`, затем `python3 -m unittest discover -s tests -p 'test_*.py'`.

В web-source после установки зависимостей: `npx tsc --noEmit -p tsconfig.selfhost.json`, затем каждый `scripts/test-*.mjs` через Node. Selfhost-конфигурация не требует отсутствующую частную Sites-конфигурацию. Для веб-сборки: `node scripts/build-selfhost.mjs ABSOLUTE_OUTPUT_DIRECTORY`.

Android: Gradle 8.11.1, JDK17, SDK35 / build-tools35.0.0; `:app:assembleRelease` создаёт неподписанный APK и проверяет DEX и binary manifest. Для проверки сервера именно из APK: `NC_TEST_APK=/absolute/file.apk python3 -m unittest discover -s tests -p test_packaged_payload.py`.
